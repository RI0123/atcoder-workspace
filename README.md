## 1.コンテスト準備

```
### ワークスペースへ移動
### ghq+fzfを入れているなら `repo atcoder` などで爆速移動可能
cd .../atcoder-workspace

### 問題ディレクトリ作成
acc new abc380
```

## 2.コーディング

VS Code で問題のファイルを開き、コードを書きます。

## 3.テスト & 提出 (acs)

問題のファイル (abc380/a/main.cpp など) を編集し終わったら、先程割り当てたショートカットキー (例: Ctrl + [) でターミナルを開き、以下を実行します。
```
acs
```

- コンパイル & テストが走ります。
- AC した場合のみ、ブラウザで提出画面が自動で開き、コードがコピーされます。
- あなたは Ctrl+V して提出ボタンを押すだけです。
- 同時に Git へのコミットも完了しています。
